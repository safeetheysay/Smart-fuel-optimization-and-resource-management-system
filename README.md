# Smart Fuel Optimization and Resource Management System

Web-based platform to monitor, plan, and optimize fuel consumption for individuals and small organizations.

Stack: React, Node.js, Express, MongoDB Atlas, OSRM, Leaflet.

Run: `npm install && npm run dev` inside both `Backend/` and `Frontend/`.

I have used mongoDB Atlas for the database , so it can be used over the network from anywhere, by anyone with the access.
